# IncuBrix Software Engineer Assessment

## Project Title

Script and Voiceover to B-roll Video Engine (PS3)

## Project Overview

This project converts a written script into narrated video content combined with B-roll footage. It provides a web interface for submitting scripts and selecting video aspect ratios.

## Technologies Used

- Python
- FastAPI
- HTML, CSS, and JavaScript
- FFmpeg
- eSpeak NG
- Docker
- Render

## Implementation

The application uses Python for backend processing, FastAPI for API endpoints, and a web interface for user interaction. eSpeak NG generates narration, while FFmpeg combines the audio and B-roll footage into a video. The application is deployed on Render.

## Features

- Script input through a web interface
- Text-to-speech narration
- B-roll video rendering
- Aspect-ratio selection
- Caption rendering, subject to successful testing
- Web-based deployment
